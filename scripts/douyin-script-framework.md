# 启点搞钱视频框架 v2.0

## 核心原则

- 搞钱是永恒主线，不可动摇
- 受众：一人公司（不限程序员，很多不会写代码）
- 先拆真实卡点，再给解法（不是鸡汤，是诊断）
- 语言犀利，敢于攻击流行认知
- 每条视频只讲一个主题，不贪多

## 五段结构

### Phase 1：宣判式钩子（0-10秒）

不是反问，是**宣判**。一句话把观众的幻觉拍碎。

句式模板：
- "X最大的死因不是A，是B。"（EP03用法）
- "X成的人死在了同一个地方。"
- "你想想你自己，是不是做了一个东西，很兴奋，然后？没有然后了。"

关键：第一句话必须是**判断句**，不是问句。让观众觉得"这个人说的是我"。

### Phase 2：三堵墙（10-70秒）

用"墙"的隐喻，列出2-3个真实障碍。每堵墙 = 一个卡点 + 为什么你赢不了。

结构：
- 第一堵墙：竞争（大厂碾压，四人优势：资本/人才/流量/品牌）
- 第二堵墙：获客（90%精力做产品，0%精力让人知道你）
- 第三堵墙：付费（大厂培养了免费习惯，你拼不起）

每个卡点用对比强化：
- 大厂 vs 一人公司
- 做产品 vs 做推广
- 国内免费 vs 海外付费

关键：每个墙都必须让观众觉得"对，我就是卡在这里"。加具体数据（"上线30天，访问量0"）把观点变成亲历。

### Phase 3：一招反转（70-100秒）

"那剩下的X成怎么活下来的？他们做了一件事：____。"

用一个反直觉的答案翻转三堵墙。答案必须：
- 简单到一句话能说清
- 但大多数人不这么做
- 直接化解前面所有卡点

### Phase 4：行动降低门槛（100-110秒）

"搞钱最反直觉的事：____。"

一句话总结 + 降低行动门槛（不需要X，不需要Y，只需要Z）。

### Phase 5：CTA（110-120秒）

评论关键词 + 下一条预告 + 钩子。

句式："评论区打'X'，下一条告诉你Y。"

## EP03实例对照

| 段落 | 内容 | 技法 |
|------|------|------|
| 钩子 | "最大的死因不是产品烂，是没人知道你活着" | 宣判式 |
| 共鸣 | "发朋友圈，发社群，然后没有然后了" | 观众代入 |
| 墙1 | 大厂四优势：资本/人才/流量/品牌 | 对比碾压 |
| 墙2 | "上线30天，访问量0" | 数据亲历 |
| 墙3 | "大厂十年培养免费习惯" | 致命一击 |
| 反转 | "不卖中国人，卖给老外" | 一句话翻转 |
| 行动 | "去海外做大厂不屑做的小需求" | 降低门槛 |
| CTA | "评论区打避坑" | 评论驱动 |

## 素材来源

| 素材类型 | 来源 |
|----------|------|
| 一人公司卡点 | 用户自身实战经历 |
| 大厂分析 | 公开信息（资本/人才/流量/品牌） |
| 海外案例 | 刘小排等方法论研究 |
| 对比数据 | 国内vs海外付费习惯、SEO数据 |

## 禁忌

- 不承诺收入（"你能赚XX"）
- 不引导私域（"加我微信"）
- 不贬低大厂（客观陈述事实，不带情绪）
- 不用已讲过的故事（每次必须有新素材）
- 不叫"程序员"（受众是一人公司，不限技术背景）

## TTS配置

- 模型：`gemini-3.1-flash-tts-preview`（铁律，不可换）
- 音色：`Aoede`
- 脚本：`node scripts/gemini-tts.cjs <input.txt> [output.mp3]`
