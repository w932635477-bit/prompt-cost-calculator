## 正文

```
Hi HN,

I built a collection of free developer tools that run entirely in the browser with no login required:

1. **AI Prompt Cost Calculator** — Paste any prompt and compare API costs across 10 models (GPT-4o, Claude Sonnet 4, Gemini 2.5, Llama 4, DeepSeek R1). Uses tiktoken for exact OpenAI token counts.

2. **Cron Expression Generator** — 161 cron expressions with plain-English explanations. Every common pattern from "every 5 minutes" to "first Monday of each month".

3. **Self-Hosted Alternatives** — Find open-source replacements for 36 SaaS tools (Slack → Mattermost, Notion → Outline, Google Drive → Nextcloud). Each with feature comparison.

4. **Docker Deploy Generator** — Copy-paste Docker Compose configs for 30 self-hosted apps. One command to deploy.

5. **Voice AI Pricing Calculator** — Compare TTS/STT costs across 6 providers (OpenAI, ElevenLabs, Deepgram, AssemblyAI, etc.) with per-minute and per-character estimates.

6. **AI Agent Safety Checklist** — 18-item checklist for production AI agents, covering prompt injection, data leakage, rate limiting, and more.

Everything is static HTML, no backend, no tracking. Built with React + Vite, hosted on Vercel.

Site: https://prompt-cost-calculator-ten.vercel.app/

Happy to answer questions about the tools or the approach.
```
